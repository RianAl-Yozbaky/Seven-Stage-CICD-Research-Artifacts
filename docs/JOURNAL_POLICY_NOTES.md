# Information and Software Technology (Elsevier): policy notes

At packaging time, Elsevier's general data guidelines described multiple policy levels (some encourage, some require data deposit). A definitive journal-specific data/code deposit mandate was not verified. Consult the current IST Guide for Authors and the editor for requirements for code, raw experimental records, and reviewer access; do not assume this summary-level deposit satisfies all rules.

- https://shop.elsevier.com/journals/information-and-software-technology/0950-5849
- https://www.elsevier.com/researcher/author/tools-and-resources/research-data/data-guidelines

The repository should not misrepresent raw evidence availability. Confidentiality and intellectual-property issues should be addressed with coauthors, the university, and the journal before public release.
