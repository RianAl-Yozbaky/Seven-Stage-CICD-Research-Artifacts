# Licensing and reuse

**No blanket open-source or open-data licence is granted by this package.** Copyright and redistribution rights should be confirmed with the authors and relevant original figure/data rights holders before publication or reuse.

The figures were copied from the author's manuscript project. CSV summaries were transcribed from the author's manuscript. The scripts in `evaluation-scripts/` were newly written for this package and should not be mistaken for the experiment's original source code.

If the authors choose an open license after review, add the appropriate `LICENSE` file and clearly specify how it applies to code, figures, and data. A public GitHub repository by itself does not grant general reuse rights.
